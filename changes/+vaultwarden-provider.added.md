Added a Vaultwarden secrets provider (also compatible with self-hosted Bitwarden). Authenticates with email + master password, decrypts personal- and organization-owned items locally using AES-CBC + HMAC-SHA256 with keys derived via PBKDF2-SHA256 or Argon2id. Organization items use RSA-OAEP-unwrapped per-organization symmetric keys. Supports retrieving the password, username, notes, TOTP seed, or any custom field of a Login item, looked up by UUID or decrypted name. Sessions (access token + decrypted keys) are cached in Django's cache framework, keyed by an HMAC of the credentials, so PBKDF2 only runs on cache miss or after a master-password rotation. Single- and multi-server configurations are supported.
